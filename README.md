# agentic-sites

A comprehensive website listing subscription-based agentic coder services that build applications from prompts.

## 🌐 Live Website

Open `index.html` in your browser or serve it with any web server.

## 🚀 Features

- **18 Agentic Coder Services** - Comprehensive list of AI-powered development platforms
- **Category Filtering** - Filter by IDE-Based, Web-Based, or Full-Stack services
- **Real-time Search** - Search across service names, descriptions, features, and pricing
- **Responsive Design** - Works seamlessly on mobile, tablet, and desktop
- **Detailed Information** - Each service includes description, features, pricing, and official links

## 🛠️ Technical Details

- **Pure HTML/CSS/JavaScript** - No build tools or dependencies required
- **Static Site** - Can be deployed anywhere (GitHub Pages, Netlify, Vercel, etc.)
- **Accessibility** - ARIA attributes for screen readers
- **Security** - XSS protection with HTML escaping
- **Performance** - Optimized search with preprocessed text

## 🚀 Quick Start

Simply open `index.html` in your browser, or serve with:

```bash
# Python
python3 -m http.server 8000

# Node.js
npx serve

# PHP
php -S localhost:8000
```

Then visit `http://localhost:8000`
